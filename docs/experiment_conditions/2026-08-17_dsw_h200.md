## 2026-08-18 数据准备状态

以下主任务资产已经在固定 revision、clean code tree 下通过审计：CIFAR-10、VOC
2012、ImageNet-100、ADE20K、NYUv2 与 AuraFlow-v0.3 FP16 权重。完整 ImageNet-1k
已放在 `$FIELDSCOPE_DATASETS_ROOT/prepared/imagenet1k`，训练入口为
`$FIELDSCOPE_DATASETS_ROOT/prepared/imagenet1k/extracted`。固定 manifest、133 万条文件

审计均已通过；条件见 `2026-08-18_dsw_h200_imagenet1k.md`。

当前修正后的 H200 recovery wrapper 最初在 GPU 7 上完成训练前预检；GPU 分配随后固定
为 GPU 6。2026-08-18 已显式设置 `CUDA_VISIBLE_DEVICES=6` 与
`FIELDSCOPE_GPU_INDEX=6`，使用生产默认的两轮、每轮 5 次资源检查重新执行
`FIELDSCOPE_RECOVERY_PREFLIGHT_ONLY=1`。两轮均通过，可用显存观测范围为
136,353--141,738 MiB，退出码为 0，并明确报告训练未启动。空闲占卡进程会在真实 CUDA
任务进入时让出算力；一个仅暴露物理 GPU 6 的 BF16 CUDA 探针已成功执行。训练前就绪
记录与机器可读报告现以 GPU 6 为当前授权条件；这仍不构成方法效果证据。

  VOC2012 独立 worker。并行范围仅为不同 dataset/task，禁止两个 worker 写同一输出目录。
- GPU 7 VOC 合同保持固定 revision、20 representations、seeds
  `4121/7319/104729`、80 epochs、batch 4、readout memory cache 0 GiB 和注册
  `selected_profile.seed_workers=1`；未修改缓存、模型、优化器或因果/裁决门。

  PID 退出时终止 GPU 7 父 worker，避免它掩盖 watchdog 对原 recovery 链的恢复判断。
- 启动审计见 `../records/2026-08-22_dsw_h200_gpu67_cross_task_parallel_launch.md`；资源重叠
  的科学影响保持 `not_inferred`，`changes_scientific_verdict=false`。
